# python-calculator

آلة حاسبة بسيطة مكتوبة بلغة Python — مشروعي في Python.

## المميزات

- جمع، طرح، ضرب، قسمة
- أس (`power`)، باقي القسمة (`modulo`)، الجذر التربيعي (`square_root`)
- قائمة تفاعلية تعمل في حلقة مستمرة حتى اختيار الخروج
- سجل لعرض العمليات السابقة
- معالجة أخطاء: القسمة على صفر، الجذر لعدد سالب، وإدخال غير رقمي
- اختبارات وحدة باستخدام `pytest`

## التشغيل

```bash
python3 main.py
```

ثم اختر رقم العملية من القائمة:

```
1. جمع
2. طرح
3. ضرب
4. قسمة
5. أس
6. باقي القسمة
7. الجذر التربيعي
8. عرض السجل
0. خروج
```

## مثال

```
اختر رقم العملية: 1
أدخل الرقم الأول: 5
أدخل الرقم الثاني: 3
النتيجة: 8.0
```

## الاختبارات

```bash
python3 -m pytest test_main.py -v
```
